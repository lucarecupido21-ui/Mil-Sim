# Mil-Sim
a fps made with claude and me and my friend

FPS milsim jouable directement dans le navigateur (un seul fichier : `index.html`, aucune dépendance à installer).

## Contrôles
- ZQSD/WASD : déplacement (Maj = sprint) · souris : viser · clic gauche : tirer · clic droit : viser
- A·E (AZERTY) ou Q·E : pencher · R : recharger · T : changer d'emplacement d'arme · G : plaque d'armure
- F : établi (zone sûre) / ouvrir ou fermer une porte · H : inspecter · B : plier/déplier la crosse (MP9) · X : loupe
- 1 à 8 : accessoires (à l'établi ou en jeu) · K : AC-130 (10 éliminations) · J : frappe de précision (5 éliminations)

## Jouer en ligne
Activer GitHub Pages : Settings → Pages → Deploy from a branch → `main` / `(root)`.
